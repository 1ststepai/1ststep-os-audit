# Project — 1stStep OS Audit & Recovery

## Product thesis
Many AI-built projects already exist before a formal operating system is created. These projects need recovery, not a fresh start.

1stStep OS Audit should:
- understand what exists
- distinguish facts from assumptions
- identify what is missing
- expose operational/business/growth gaps as well as code gaps
- produce an actionable recovery plan
- generate or repair the target project's Project OS
- verify remediation over time

## Product entry point
"Already started building? Connect your project and we'll tell you what you missed."

## Primary users
- vibe coders with an existing repository
- developers inheriting AI-generated code
- founders with partially built SaaS/apps
- businesses modernizing legacy systems
- teams preparing for launch
- agencies auditing client builds

## Companion relationship
1stStep OS generates and governs new projects.
1stStep OS Audit imports, evaluates, and recovers existing projects.
