# 0.2.0 developer preview — compact offline review

Repeatedly supplying a full audit report can consume unnecessary AI context. This release adds a compact first-read summary with source identity, coverage, review candidates and pointers to the full evidence. Users can expand only the relevant evidence when working with an assistant.

## Measured example

One internal SwingTradePros source snapshot, 1,369 files:

| Measure | Result |
|---|---:|
| Previous full report used for initial review | 60,049 bytes |
| New compact first-read summary | 5,849 bytes |
| Initial payload reduction | 90.26% |
| New full evidence report, retained separately | 139,398 bytes |
| Page source files inventoried | 79 |
| App Router routes parsed | 124 |
| Model calls / paid API calls in the offline audit | 0 / 0 |

The source content manifest was identical between runs. These are internal measurements on one project, not an independent benchmark. Report paths/timestamps change serialized size slightly. We have not measured actual token counts, total assistant usage, billed savings or review accuracy. Reading the full report as well as the summary can increase total context. The saving depends on reading the summary first and selectively expanding evidence.

## Changes

- Next.js App Router source inventory and file/line/hash references.
- Separate review queue for wildcard data selections and data mutations. These are patterns to investigate, not confirmed vulnerabilities.
- Conventional test-file inventory compared with explicit root `node --test` selection. Other scripts, imports and CI coverage remain unknown.
- Template environment filenames no longer trigger the tracked-sensitive-filename alarm; no credential validity is inferred.
- More conventional release-guidance paths recognized as documentation.
- Optional `--summary` JSON output, capped samples, omitted-item counts and no source excerpts.
- Reuses pinned TypeScript 5.9.3 locally; no new model service, account or subscription.

## Validation and limits

Type checking, all 26 tests and the zero-metered-cost gate passed locally. Tests exercise AST parsing, misleading comments/strings, malformed/oversized files, review-sample coverage, test-selection unknowns, template exclusions, immutable output and output-junction safety. Network calls are blocked in a regression test that exercises the AST path. No customer source, credentials, audit-store objects or private audit findings are shipped with this release.

The engine still returns PARTIAL / NOT ASSESSED. Rendered UI, authenticated behavior, authorization effectiveness, payments and deployed runtime require separate verification. Local CPU/storage are not free. No result cache or automated repair is introduced.

Follow the README setup with the pinned companion repository and line-ending conversion disabled for that clone. The contract hashes remain exact; they are not relaxed for Windows. No hosted service or npm package is deployed by this GitHub prerelease.
