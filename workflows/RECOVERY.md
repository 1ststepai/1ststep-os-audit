# Recovery Workflow

Baseline must already be finalized.

Then:
1. map findings to remediation tasks
2. order by severity/dependency/risk/value
3. separate P0/P1/P2
4. define target Project OS files
5. execute scoped remediation cycles
6. mark changes REMEDIATED
7. independently verify
8. mark VERIFIED only with evidence
9. recalculate current scores
10. preserve baseline scores
